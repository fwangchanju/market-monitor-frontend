# Fonts

- `press-start-2p.woff2` — [Press Start 2P](https://fonts.google.com/specimen/Press+Start+2P), SIL Open Font License 1.1. 라틴 문자/숫자만 커버.
- `galmuri11.woff2` — [Galmuri](https://galmuri.quiple.dev)의 Galmuri11, SIL Open Font License 1.1 (`GALMURI-LICENSE.txt` 참고). 한글 커버.

nes.css의 픽셀 폰트 톤을 유지하면서 한글까지 커버하기 위해 두 폰트를 `font-family: "Press Start 2P", "Galmuri11", sans-serif`로 함께 사용한다.
