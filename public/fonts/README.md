# Fonts

- `pretendard-regular.woff2`, `pretendard-bold.woff2` — [Pretendard](https://github.com/orioncactus/pretendard), SIL Open Font License 1.1. 한글/라틴/숫자 전부 단일 패밀리로 커버. Gmarket Sans의 폴백으로 쓰인다.
- `gmarket-sans-light.woff2`(300), `gmarket-sans-medium.woff2`(500), `gmarket-sans-bold.woff2`(700) — [지마켓 산스](https://corp.gmarket.com/fonts/), 지마켓이 무료 배포하는 폰트([fonts-archive/GmarketSans](https://github.com/fonts-archive/GmarketSans) 미러에서 받음). 전체 화면 기본 폰트.

`font-family: "Gmarket Sans", "Pretendard", sans-serif`로 사용한다.
